VENUS

Visual Encoding for kNowledge graphs Understanding and exploration Systems

JavaScript library designed to support the development of interactive visualizations directly from SPARQL queries.

Open Editor

Build Interactive Visualizations

VENUS is a visual specification workbench for knowledge graphs. It allows you to transform SPARQL query results into interactive visualizations through a declarative configuration interface. Instead of hard-coding mappings or manually reshaping data, you iteratively define structural encodings, preview the result in real time, and export a reusable specification ready for integration into your own application.
Experiment with configurations, inspect how semantic variables map to visual structures, and refine your design before committing it to code. VENUS shortens the path from knowledge graph to visualization by making structural mapping explicit, testable, and reproducible.
If you work with RDF, SPARQL, or semantic data pipelines, VENUS provides a controlled environment to prototype, validate, and deploy visualization specifications with precision.
Validate and refine your encoding in the Online Editor before integrating it into your codebase.
