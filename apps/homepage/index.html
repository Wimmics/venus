Usage

Minimal example to import and use a Venus component in a web page:

<script type="module">
  import "@wimmics/venus-webcomponents";

  const graph = document.querySelector("vis-graph");
  graph.sparqlEndpoint = "https://dbpedia.org/sparql";
  graph.sparqlQuery = "SELECT ?source ?target WHERE { ?source dbo:starring ?target } LIMIT 30";
  graph.encoding = { title: "Example Graph" };
  graph.launch();
</script>
