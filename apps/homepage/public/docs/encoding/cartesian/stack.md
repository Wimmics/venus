# Stack

The `stack` property controls grouped/stacked behavior in cartesian charts.

```js
encoding: {
  stack: false
}
```

## Properties

| Property | Type | Description |
|---|---|---|
| `stack` | `string`/`boolean` | Stack mode for charts. Possible values: `false` (grouped), `true` (stacked), `"normalize"` (100% stacked proportions). <br>**Default:** `false`. |
