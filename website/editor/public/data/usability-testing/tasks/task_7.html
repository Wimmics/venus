Task 7 – Free Exploration

Goal

Use VENUS to explore the DBpedia knowledge graph by:

  • writing your own SPARQL query or selecting one of the provided query examples;
  • creating a visualization using one of the visualization types explored in the previous tasks (bar chart, directional graph, or Sankey diagram);
  • modifying the SPARQL query, the visualization encoding, or both, to answer a question or highlight an interesting aspect of the data.

This task is intentionally open-ended. Feel free to experiment with different SPARQL queries, visualization encodings, and editor features to create a visualization that you find meaningful.
