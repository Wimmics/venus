Task 7 – Free Exploration

In this final task, you may freely explore the DBpedia knowledge graph using VENUS.

Goal: Write your own SPARQL query and create a visualization using one of the visualization types explored in the previous tasks (bar chart, force-directed graph, or Sankey diagram). You may customize both the query and the visualization encoding as you wish.

Your objective is to create a visualization that effectively answers a question or reveals an interesting aspect of the DBpedia knowledge graph.

There is no single correct solution for this task. Feel free to be creative and use any combination of data, visual encodings, and interactions supported by VENUS.
