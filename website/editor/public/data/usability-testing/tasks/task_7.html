Task 7 – Free Exploration

In this final task, you are free to explore the DBpedia knowledge graph using VENUS.

Goal:

  • Write your own SPARQL query or choose one of the proposed queries.
  • Create a visualization using one of the visualization types explored in the previous tasks (bar chart, force-directed graph, or Sankey diagram).
  • Modify the SPARQL query, the visualization encoding, or both, to answer a question or reveal an interesting aspect of the data.

There is no single correct solution for this task. Feel free to experiment with different queries, visual encodings, and interactions supported by VENUS.
