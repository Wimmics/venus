Task 5 – Modify a Sankey Diagram

Goal

Modify the provided Sankey diagram encoding so that the Language stage is sorted according to the number of incoming links.

You are provided with a SPARQL query and the encoding of a Sankey diagram.

If you are not familiar with this type of visualization, the figure below illustrates how to interpret it. The example is provided for explanation purposes only and is not related to the data used in this task.

How to Read a Sankey Diagram

A Sankey diagram represents the flow of items through a sequence of stages. Each rectangle corresponds to a category at a given stage, while the links between rectangles represent the flow of items from one category to another. The width of each link is proportional to the quantity it represents.

In this task, the Sankey diagram represents the flow of movies through three stages: Studio, Runtime Category, and Language. The width of each link corresponds to the number of movies represented by that flow.

SPARQL Query Description

The provided query retrieves information about the 30 film studios with the largest number of movies in DBpedia. For each studio, movies are grouped into runtime categories and languages, and the number of movies in each combination is counted.

The query returns the following fields:

  • Studio — the name of the film studio.
  • Runtime Category — one of four runtime intervals: 40–90 min, 90–120 min, 120–150 min, or 150–240 min.
  • Language — the language associated with the movies.
  • Number of Movies — the number of movies belonging to each combination of studio, runtime category, and language.
