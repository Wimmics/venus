Task 5 – Modify a Sankey Diagram

In this task, you are provided with a SPARQL query and the encoding of a Sankey diagram. The diagram represents the flow of movies through three stages: studio, runtime category, and language. The width of each link is proportional to the number of movies it represents.

Goal: Modify the encoding so that the language stage is sorted according to the number of incoming links.

Restriction: Do not modify the SPARQL query.
