Task 5 – Modify a Sankey Diagram

In this task, you are provided with a SPARQL query and the encoding of a Sankey diagram.

If you are not familiar with this type of visualization, the figure below illustrates how to interpret it (the example is for explanation purposes only and is not related to the data used in this task).

A Sankey diagram represents the flow of items through a sequence of stages. Each rectangle corresponds to a category at a given stage, while the links between rectangles represent the flow of items from one category to another. The width of each link is proportional to the quantity it represents.

In this task, the Sankey diagram shows the flow of movies through three stages: studio, runtime category, and language. The width of each link corresponds to the number of movies represented by that flow.

Goal: Modify the encoding so that the language stage is sorted according to the number of incoming links.

Restriction: Do not modify the SPARQL query.
