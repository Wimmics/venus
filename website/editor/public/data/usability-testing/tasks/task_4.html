Task 4 – Create a Force-Directed Graph

In this task, you are provided with a SPARQL query and an empty encoding panel.

Goal: Create a force-directed graph that represents actors and movies as nodes, with directed links connecting each actor to the movies in which they appeared. Complete the encoding so that:

  • Movie nodes are colored according to the studio that produced them.
  • Actor nodes display the value of actorName as their label.
  • Movie nodes display the value of movieName as their label.

Restriction: Do not modify the SPARQL query.
