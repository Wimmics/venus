Task 5 – Create a Directional Graph

Goal

Create a directional graph that:

  • represents actors and movies as nodes;
  • connects each actor to the movies in which they appeared using directed links;
  • colors movie nodes according to the producing studio;
  • uses actorName as the label of actor nodes;
  • uses movieName as the label of movie nodes.

You are provided with a SPARQL query and an empty visualization encoding. Create the visualization by defining the required encoding.

Hint: Zoom in to view the graph labels and verify your results.

SPARQL Query Description

The provided query retrieves information about movies, the actors starring in them, their film studios, languages, and runtime. Only movies with a runtime between 40 minutes and 4 hours are included.

The query returns the following fields:

  • Movie — the name of the movie.
  • Actor — the name of an actor starring in the movie.
  • Studio — the name of the film studio.
  • Language — the language of the movie.
  • Runtime — the movie runtime, expressed in seconds.
