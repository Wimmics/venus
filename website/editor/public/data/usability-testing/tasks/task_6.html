Task 6 – Create a Sankey Diagram

Goal

Create a Sankey diagram that:

  • represents the flow of movies through the Studio, Runtime Category, and Language stages;
  • assigns a title to each stage;
  • colors all stages according to the runtime category.

You are provided with a SPARQL query and an empty visualization encoding. Create the visualization by defining the required encoding.

SPARQL Query Description

The provided query retrieves information about the 30 film studios with the largest number of movies in DBpedia. For each studio, movies are grouped into runtime categories and languages, and the number of movies in each combination is counted.

The query returns the following fields:

  • Studio — the name of the film studio.
  • Runtime Category — one of four runtime intervals: 40–90 min, 90–120 min, 120–150 min, or 150–240 min.
  • Language — the language associated with the movies.
  • Number of Movies — the number of movies belonging to each combination of studio, runtime category, and language.
