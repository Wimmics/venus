Task 6 – Create a Sankey Diagram

In this task, you are provided with a SPARQL query and an empty encoding panel.

Goal: Create a Sankey diagram representing the flow of movies through the studio, runtime category, and language stages. Complete the encoding so that:

  • Each stage displays a custom title.
  • All stages are colored according to the corresponding runtime category.

Restriction: Do not modify the SPARQL query.
