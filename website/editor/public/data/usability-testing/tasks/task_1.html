Task 1 – Modify a Bar Chart

In this task, you will be provided with a SPARQL query and the basic encoding of a bar chart. The encoding already defines the x- and y-axis mappings using the SPARQL variables studioName and nbMovies, respectively.

Goal: Complete the visualization by modifying the encoding so that:

  • bars are colored according to the movie language.

Restriction: Do not modify the SPARQL query.
