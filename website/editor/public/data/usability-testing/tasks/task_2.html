Task 2 – Create a Stacked Bar Chart

Goal

Create a stacked bar chart that:

  • displays the studios on the x-axis;
  • displays the number of movies on the y-axis;
  • stacks the bars according to the movie language;
  • uses the Set2 color palette.

You are provided with a SPARQL query and an empty visualization encoding. Create the visualization by defining the required encoding.

SPARQL Query Description

The provided query retrieves information about the 20 film studios with the largest number of movies in DBpedia. For each studio, it groups the movies by language and counts how many movies are available.

The query returns the following fields:

  • Studio — the name of the film studio.
  • Language — the language associated with the movies.
  • Number of Movies — the number of movies produced by the studio in that language.
