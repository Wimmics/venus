Task 2 – Create a Stacked Bar Chart

In this task, you are provided with a SPARQL query and an empty encoding panel.

Goal:

  • Create a stacked bar chart using the provided query.
  • Display the studios on the x-axis and the number of movies on the y-axis.
  • Stack the bars by the movies' language.
  • Use the Set2 color palette.

Restriction: Do not modify the SPARQL query.
