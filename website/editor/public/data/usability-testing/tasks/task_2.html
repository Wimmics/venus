Task 2 – Create a Bar Chart

In this task, you will be provided with a SPARQL query and an empty encoding panel.

Goal: Recreate the bar chart from the previous task using the provided query. The chart should display the number of movies produced by each studio, with the x-axis representing the studios and the y-axis representing the number of movies. Bars should be colored according to the movies' language.

Then, further customize the visualization by:

  • Using the Set2 color palette.
  • Stacking the bars so that all languages produced by the same studio are displayed within a single bar.

Restriction: Do not modify the SPARQL query.
