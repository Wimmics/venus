Task 4 – Modify a Directional Graph

Goal

Modify the provided directional graph encoding so that the size of each target node is proportional to the runtime of the associated movie.

You are provided with a SPARQL query and the basic encoding of a directional graph. The encoding already defines the graph structure using the SPARQL variables actor and movie, producing a network where actors are connected to the movies they appeared in.

SPARQL Query Description

The provided query retrieves information about movies, the actors starring in them, their film studios, languages, and runtime. Only movies with a runtime between 40 minutes and 4 hours are included.

The query returns the following fields:

  • Movie — the name of the movie.
  • Actor — the name of an actor starring in the movie.
  • Studio — the name of the film studio.
  • Language — the language of the movie.
  • Runtime — the movie runtime, expressed in seconds.
