Task 4 – Modify a Directional Graph

In this task, you will be provided with a SPARQL query and the basic encoding of a directional graph. The encoding already defines nodes and links using the SPARQL variables actor and movie. This visualization displays actors linked to movies they worked on.

Goal: Modify the encoding so that the size of each target node is proportional to the runtime of the associated movie.

Restriction: Do not modify the SPARQL query.
