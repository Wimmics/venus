Creating Visualizations with VENUS

Before exploring the editor, it is helpful to become familiar with a few basic concepts used throughout the study.

A visualization encoding is composed of a few recurring concepts:

  • Data fields are the variables returned by the SPARQL query (or contained in the SPARQL JSON results). They are used to define the graphical elements of the visualization and how they represent the data.
  • Marks define the graphical elements of the visualization, such as bars, nodes, links, lines, or points.
  • Visual variables (or channels) determine how marks visually represent the data. Examples include color, size, opacity, and stroke.
  • Annotations add textual information to the visualization, such as labels and tooltips.
