# Marks Orientation

The `direction` property sets the orientation of marks. 

```js
encoding: {
  direction: "vertical"
}
```

## Properties

| Property | Type | Description |
|---|---|---|
| `direction` | `string` | Mark orientation mode. Possible values: `"vertical"` (columns) or `"horizontal"` (rows). <br>**Default:** `"vertical"`. |
