Using Venus in a Web Page

VENUS is distributed as an npm package and can be directly embedded into web pages, as shown hereafter.

Get Venus and Dependencies

CDN

For quick experiments, you can import Venus Web Components directly from a CDN inside a module script. 

<script type="module">
	import "https://cdn.jsdelivr.net/npm/@wimmics/venus-elements@0.1.0/dist/index.js";
</script>

NPM

For production or app builds (Vite, Webpack, etc.), install from npm and import from your app entry file. 

npm install @wimmics/venus-elements
import "@wimmics/venus-elements";

Start Using Venus

Create a target element in your HTML:

<venus-graph id="vis" width="100%" height="520"></venus-graph>

Then configure and launch it from JavaScript:

const graph = document.querySelector("#vis");
					
graph.sparqlEndpoint = "https://dbpedia.org/sparql";

graph.sparqlQuery = `
SELECT ?source ?target WHERE {
	?source dbo:starring ?target .
} LIMIT 30
`;

graph.encoding = {
	title: "Actors Co-starring Graph",
	interactions: { nodeDetailsPanel: true }
};

graph.launch();

Complete HTML Example

<!doctype html>
<html>
<head>
	<meta charset="utf-8" />
	<meta name="viewport" content="width=device-width,initial-scale=1" />
	<title>Embedding Venus</title>
</head>
<body>
	<venus-graph id="vis" width="100%" height="520"></venus-graph>

	<script type="module">
		import "@wimmics/venus-elements";

		const graph = document.querySelector("#vis");
		
		graph.sparqlEndpoint = "https://dbpedia.org/sparql";
		
		graph.sparqlQuery = `
		SELECT ?source ?target WHERE {
			?source dbo:starring ?target .
		} LIMIT 30
		`;

		graph.encoding = {
			title: "Actors Co-starring Graph",
			interactions: { nodeDetailsPanel: true }
		};

		graph.launch();
	</script>
</body>
</html>
