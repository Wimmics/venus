# @wimmics/venus-legends

Legend web components and legend factory utilities.

## Responsibilities
- Provide color and size legend custom elements.
- Build legend instances from current encoding configuration.
- Position legends in visualization containers.

## Package Links
- Depends on:
  - No internal Venus packages.
- Used by:
  - `@wimmics/venus-components` (`vis-graph` and `vis-barchart` legend lifecycle management).
