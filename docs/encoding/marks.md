## Marks

Marks are the basic visual building block of a visualization. They provide basic shapes whose properties (such as position, size, and color) can be used to visually encode data, either from a data field, or a constant value. Venus currently supports the following marks:

| Mark | Description |
|---|---|
| `bars` | A rectangle-shaped mark representing a quantitative value through its length or height.  |
| `lines` | A line-shaped mark connecting data points to represent relationships or trends. |
| `points` | A dot-shaped mark representing an individual data item at a specific position. |
| `nodes` | A circle-shaped mark representing an entity or object in a graph. |
| `links` | A line-shaped mark representing a relationship or connection between two nodes. |

Multiple marks can be combined within a single visualization. For example, a line chart may include both lines and points, where points represent individual data values. 

See [`Visualization Components`](../visualization-components/start.md) for details on each mark and the marks supported by each visualization technique.
