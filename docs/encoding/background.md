# background

`background` defines the chart background color.

## Position in Encoding

```js
encoding: {
  background: "#ffffff"
}
```

## Properties

| Property | Type | Description |
|---|---|---|
| `background` | `string` | CSS color string used as chart background. Possible values: any valid CSS color (for example `"#ffffff"`, `"white"`, `rgb(...)`). Default: `"#ffffff"`. |
